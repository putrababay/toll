Kenapa saldo belum otomatis keluar?

Browser (Chrome) dibatasi standar W3C hanya untuk membaca ID fisik kartu (UID). Sektor saldo & mutasi bank (e-Money / Flazz) diproteksi enkripsi ISO-DEP APDU yang hanya bisa diakses via aplikasi perbankan (Livin / BCA Mobile).

Silakan simpan saldo fisik aktual kartu Anda ke penyimpanan HP ini agar otomatis tersimpan permanen!

Windows Memblokir Akses USB CCID Bawaan

Di Windows, driver Microsoft Usbccid mengunci reader ACR122U secara eksklusif sehingga Chrome ditolak (Access Denied).

Solusi Driver WinUSB (Cukup 1x set):

  1. Unduh tool gratis Zadig (zadig.akeo.ie)
  2. Buka Zadig > klik menu Options > centang List All Devices
  3. Pilih ACR122U PICC Interface di dropdown
  4. Pastikan driver tujuan adalah WinUSB, lalu klik tombol Replace Driver
  5. Kembali ke sini dan klik Hubungkan Reader.

*Atau jika tidak ingin mengganti driver, gunakan tab Auto-Scan Keyboard atau Local Bridge di atas.

Cara Menggunakan:

1. Cukup colokkan reader USB ke PC (lampu alat menyala).

2. Tempelkan kartu e-Toll Anda di atas reader USB.

3. Alat akan otomatis membunyikan beep dan nomor kartu langsung terisi di aplikasi ini tanpa perlu instal driver!

*Sistem mendengarkan ketikan scanner otomatis di seluruh halaman secara global.
